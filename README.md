# ⏳ Countdown Event Manager

A modern and interactive **Countdown Event Manager** built using **HTML, CSS, and JavaScript**.
This project allows users to create, manage, and track multiple countdown events in real time with a clean and responsive user interface.

Perfect for tracking birthdays, exams, product launches, holidays, meetings, travel plans, and more.

---

### 🔗 Live Preview: https://abdurrahmancce.github.io/Countdown-Event-Manager/

---

## ✨ Live Features

✅ Create multiple countdown events

✅ Real-time auto-updating timers

✅ Edit and delete events

✅ Event filtering and sorting

✅ Search functionality

✅ Dark & Light mode support

✅ Beautiful modern UI design

✅ Progress tracking bar

✅ LocalStorage data persistence

✅ Event notifications

✅ Celebration animation when countdown ends

✅ Import & export event data

✅ Fully responsive design

# 🚀 Features Breakdown

## 📅 Event Management

* Add new events
* Edit existing events
* Delete events
* Event categories with icons
* Custom event colors

## ⏱️ Live Countdown Timer

* Auto updates every second
* Displays:

  * Days
  * Hours
  * Minutes
  * Seconds

## 🔎 Search & Filter

Filter events by:

* All Events
* Upcoming
* Expired

Search events instantly by title or category.

## 📊 Progress Tracking

Each event includes:

* Dynamic progress bar
* Remaining percentage display

## 🔔 Notifications

Optional reminder system:

* 15 minutes before
* 30 minutes before
* 1 hour before
* 1 day before

## 🎉 Celebration System

When an event reaches zero:

* Celebration popup appears
* Confetti animation starts
* Event automatically moves to expired state

## 🌙 Theme Support

* Dark mode
* Light mode
* Theme saved using localStorage

## 📤 Export & Import

Users can:

* Export events as JSON
* Import saved events anytime
